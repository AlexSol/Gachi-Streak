# Assets

Оригінальні картинки й звуки, згенеровані для цього проєкту (Python + Pillow + NumPy, без сторонніх матеріалів). Можна вільно використовувати й змінювати.

| Папка | Що там | Коли |
|---|---|---|
| `images/warning` | 5 шпалер «♂ dungeon ♂» в стилі попередження | ≤ 5 год до дедлайну |
| `sounds/warning` | гонг, удар батога, тік-так + будильник | вхід у попередження |
| `sounds/failed` | сумний тромбон, баззер, сирена, 8-bit game over | провал |

Клієнт вшиває їх у `.exe` і при першому запуску розпаковує у `%APPDATA%\GachiStreak\images\…` та `…\sounds\…`, якщо ці папки порожні. Свої картинки чи `.wav/.mp3` просто клади поруч — береться випадковий файл із папки.
