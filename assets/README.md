# Assets

Оригінальні картинки й звуки, згенеровані для цього проєкту (Python + Pillow + NumPy, без сторонніх матеріалів). Можна вільно використовувати й змінювати.

| Папка | Що там | Коли |
|---|---|---|
| `images/warning` | 5 шпалер «♂ dungeon ♂» в стилі попередження | ≤ 5 год до дедлайну |
| `sounds/warning` | гонг, удар батога, тік-так + будильник | вхід у попередження |
| `sounds/failed` | сумний тромбон, баззер, сирена, 8-bit game over | провал |
| `widget/safe` | WebM: релакс у басейні | фон віджета, на сьогодні зараховано |
| `widget/pending` | WebM: перекур, Billy спить | фон віджета, активності ще нема |
| `widget/warning` | WebM: суворий погляд з вусами | фон віджета, ≤ 5 год до дедлайну |
| `widget/failed` | анімований WebP: Billy в червоному світлі | фон віджета, провал |

> ⚠️ `widget/*` **не** згенеровані: це конвертовані gachimuchi-кліпи (Catalina Collection, MakeAGIF), на них поширюються права власників. Оригінали лежать у [`assets-src/widget`](../assets-src/widget), перезібрати: `assets-src/widget/convert.sh` (потрібен ffmpeg з libvpx-vp9 і libwebp).

Клієнт вшиває їх у `.exe` і при першому запуску розпаковує у `%APPDATA%\GachiStreak\images\…`, `…\sounds\…` та `…\widget\<стан>`, якщо ці папки порожні. Свої картинки чи `.wav/.mp3` просто клади поруч — береться випадковий файл із папки.
